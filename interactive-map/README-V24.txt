V24 SINGLE SOURCE

This package changes only the interactive-map folder.
Tour pages are NOT included or overwritten.
Every map card fetches live data from the original site page at /tours/<filename>.html.
VIEW TOUR opens the same original page.
Changing title, price, description, duration, transfer text or hero image in the original tour page is reflected in the map after deployment and refresh.
IMPORTANT: renaming the HTML filename itself requires updating the page value in data/tours.json, because a static website cannot discover renamed files automatically.
