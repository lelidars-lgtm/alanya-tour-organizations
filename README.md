# ALANYA TOUR ORGANIZATIONS

Готовый сайт под Vercel.

## Как запустить локально
npm install
npm run dev

## Как загрузить на Vercel
1. Зайди на https://vercel.com
2. New Project
3. Upload / Import этот проект
4. Framework: Vite
5. Build command: npm run build
6. Output directory: dist
7. Deploy
