REAL VISITOR GEOLOCATION
- SHOW MY LOCATION requests browser geolocation only after a click.
- navigator.geolocation.watchPosition keeps the user's point live.
- If the visitor is inside Türkiye, a cyan YOU ARE HERE point appears on the same SVG.
- If outside Türkiye, coordinates are read but the point is not drawn outside the map.
- Clicking again stops live tracking.

IMPORTANT
- HTTPS is required for browser geolocation. Vercel satisfies this.
- Browser/user permission is still required.
- No automatic location prompt is fired on page load.
